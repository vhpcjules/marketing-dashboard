The connectors can display these files but cannot write their bytes to disk,
so they must be added to the repo by hand. Source folder:

`VBPInformation › Shared Documents › General › Branding & Logos › Versatile › Logos - Digital › VHPC registered trademark`

Copy in, keeping these names:

| Use | Source file | Save as |
|---|---|---|
| Header on the Deep Blue band | `VHPC_MultiWhite.png` (white wordmark, Aqua Blue V-stroke) | `assets/logo/vhpc-white.png` |
| Light surfaces (print, index card) | `VHPC_MultiBlu.png` | `assets/logo/vhpc-blue.png` |

The lockup is two lines — VERSATILE over HIGH-PERFORMANCE COATINGS® — at
roughly 4.3:1. Exclusion zone per the brand guidelines: clear space equal to
the cap height of the wordmark on all sides (60px at the 2000px master;
scale proportionally). The header component reserves this as padding.

VHPC and Versatile are the same company; the `VHPC_` files are the full
two-line lockup, the `Versatile_` files are the wordmark alone.
